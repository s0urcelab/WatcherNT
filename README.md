<h1 align="center">WatcherNT</h1>

<p align="center">
  Windows 程序保活与自动更新工具
</p>

WatcherNT 可以集中管理需要长期运行的 Windows 程序。当受管程序意外退出时，它会自动重新启动；发现新版本时，也可以完成下载、替换和重启。日常运行时 WatcherNT 会收纳到系统托盘，不占用任务栏空间。

## 主要功能

- **程序保活**：定时检查运行状态，程序意外退出后自动重新启动
- **多程序管理**：统一添加、编辑、启动、停止和查看多个程序
- **自动更新**：按设定周期检查更新，发现新版本后自动安装
- **安全回滚**：更新失败时尝试恢复原文件，并重新启动原版本
- **运行日志**：直接查看由 WatcherNT 启动的程序所输出的日志
- **系统托盘**：关闭主窗口后继续在后台运行，随时从托盘重新打开
- **登录自启动**：可设置在当前用户登录 Windows 时自动启动

## 适用场景

- 守护需要持续运行的本地服务或工具
- 管理没有自带自动更新功能的内部程序
- 为内网部署的小型应用提供简单的保活和更新能力

> WatcherNT 不是 Windows 服务。只有在用户已登录且 WatcherNT 正在运行时，保活和自动更新才会生效。

## 自动更新说明

WatcherNT 通过 HTTP(S) 文件索引查找最新的 `.exe` 文件。更新文件名中需要包含一个 **7 位十六进制版本标识**，例如：

```text
my-app-32eda5f.exe
```

启用自动更新后，可以按分钟、小时或天设置检查周期。发现版本变化时，WatcherNT 会：

1. 下载新版本
2. 停止目标程序
3. 备份并替换原可执行文件
4. 按配置启动新版本
5. 在失败时尝试恢复原版本

为了避免更新失败：

- 建议使用 HTTPS 更新地址；HTTP 仅适合可信内网
- 请将受管程序放在当前用户有写入权限的目录
- 单个更新文件不能超过 512 MiB

## 日志与数据

WatcherNT 的配置和日志保存在：

```text
%LOCALAPPDATA%\WatcherNT
```

主窗口底部会显示当前所选程序的日志。WatcherNT 只能捕获由它启动后的标准输出和错误输出，无法读取程序此前的历史输出。

## 系统要求

- Windows 10 或更高版本
